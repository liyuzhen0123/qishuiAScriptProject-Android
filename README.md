# 汽水音乐自动看广告脚本（优化版）

本项目基于开源项目 [sw78159/qishui-auto]([https://github.com/cvabm/qishui](https://github.com/sw78159/qishui-auto)) 进行二次开发与逻辑优化，使用 **OCR 文字识别** 定位按钮，再通过 adb 模拟点击。

---

## 功能特点

1. **OCR 识别按钮**：识别「领取奖励」「继续观看」「领取成功」「继续互动」四类目标，不依赖固定坐标。
2. **支持互动弹窗**：识别到「完成互动，领取奖励福利」弹窗时，会点击绿色「继续互动」按钮。
3. **智能过滤误点**：自动排除标题、倒计时、弹窗说明文字，例如：
   - `09秒后可领取奖励`
   - `再看XX秒继续解锁`
   - `完成互动，领取奖励福利`
   - `坚持退出`
4. **秒退直播间**：屏幕顶部出现「关注」「更多直播」时，立即按返回键退出。
5. **防卡死兜底**：连续 5 次没识别到目标，自动按返回键尝试退出异常页面。
6. **adb 自动查找**：自动从脚本目录、系统 PATH、Android SDK 环境变量中查找 `adb.exe`。
7. **截图兼容处理**：自动跳过部分 adb 在截图前打印的警告文本，避免截图解码失败。
8. **点击调试截图**：每次点击都会在 `debug_clicks/` 目录保存带标记的图片，方便排查误点。

## 电脑小白手把手使用教程

### 第一步：手机设置（只需设置一次）

1. 打开手机的 **「设置」** → **「关于手机」**。
2. 连续快速点击 **「版本号」** 7 次以上，直到提示已开启开发者模式。
3. 返回设置页面，找到 **「开发者选项」**。
4. 开启以下开关：
   - **USB 调试**（必须开启）
   - **USB 调试（安全设置）** 或 **允许模拟点击**（小米 / vivo 等机型必开，否则脚本只能看不能点）
5. 用**数据线**把手机连接到电脑。
6. 手机弹窗「是否允许 USB 调试」时点 **允许**，建议勾选「始终允许」。如果没弹窗，重新插拔数据线或锁屏再解锁一次。

---

### 第二步：安装电脑运行环境

1. 确保电脑已安装 **Python 3**。
2. 在本项目文件夹上方的地址栏输入 `cmd` 并按回车，打开命令行。
3. 安装 Python 依赖：

   ```bash
   pip install -r requirements.txt
   ```

4. **安装 adb（关键，不能跳过）**：

   Python 依赖里不包含 adb，需要单独下载：

   - 打开 Android 官方页面：<https://developer.android.com/tools/releases/platform-tools>
   - 下载 Windows 版 platform-tools 压缩包
   - 解压后找到 `adb.exe`
   - 把 `adb.exe` 复制到本项目目录，和 `qishui_auto.py` 放在一起

   也可以把 `adb.exe` 的绝对路径填到脚本顶部的 `ADB_PATH`，或把 platform-tools 目录加入系统 PATH。

5. 验证 adb 是否连上手机：

   ```cmd
   .\adb.exe devices
   ```

   正常应显示类似：

   ```text
   1ade4ba8    device
   ```

   如果显示 `unauthorized`，说明手机上还没点允许 USB 调试；如果列表为空，检查数据线和手机授权。

---

### 第三步：开始使用

1. 手机打开 **汽水音乐**，进入看广告领时长页面。
2. 保持手机屏幕常亮，不要锁屏。
3. 双击运行 **`启动.bat`**，或在命令行运行：

   ```cmd
   python qishui_auto.py
   ```

4. 正常启动后会看到类似输出：

   ```text
   🚀 汽水音乐自动看广告脚本启动（OCR 文字识别）
   ✅ 使用 adb: D:\Desktop\py_project\qishui-auto\adb.exe
   ⏳ 加载 OCR 模型...
   ✅ OCR 就绪
   ```

5. 之后脚本会自动循环截图、识别、点击，无需人工干预。

## 识别目标与点击规则

| 目标文字 | 点击区域 | 说明 |
| --- | --- | --- |
| `领取奖励` | 屏幕中央 | 领取奖励按钮 |
| `继续观看` | 屏幕中央 | 继续看广告按钮 |
| `领取成功` | 几乎全屏 | 点完后不进入冷却，立即继续识别 |
| `继续互动` | 屏幕中央弹窗 | 「完成互动，领取奖励福利」弹窗里的绿色按钮 |

点击优先级按上表从上到下。  
包含 `秒`、`解锁`、`后可领取`、`第`、`福利`、`完成互动`、`坚持退出` 的文字不会被点击，避免误点标题或倒计时。

## 常见问题

### 1. 报错 `[WinError 2] 系统找不到指定的文件`

说明电脑找不到 adb。把 `adb.exe` 放到脚本同目录，或修改脚本顶部的 `ADB_PATH`。

### 2. 提示 `截图失败，检查 adb 连接`

按下面顺序检查：

1. 执行 `.\adb.exe devices`，确认状态是 `device` 而不是 `unauthorized`
2. 手机是否解锁、是否弹出允许 USB 调试
3. 数据线是否是数据线而不是仅充电线
4. 脚本已兼容 adb 截图前的警告文本，如果仍失败，会打印具体原因

### 3. 一直点标题，或者不点「继续互动」

脚本已过滤 `完成互动，领取奖励福利` 这类标题，并支持点击「继续互动」。  
如果仍异常，打开 `debug_clicks/` 目录查看带红十字的调试截图，确认实际点到了哪里。

### 4. 识别不到按钮

绿色艺术字可能导致 OCR 置信度偏低，可以把脚本顶部的：

```python
OCR_SCORE = 0.5
```

适当调低到 `0.4`。

### 5. 如何退出

在电脑黑窗口按快捷键：

```text
Ctrl + C
```

## 进阶配置（可选）

脚本顶部集中放了大量可调参数，常用如下：

| 参数 | 说明 |
| --- | --- |
| `TARGETS` | 要识别并点击的文字列表 |
| `OCR_SCORE` | OCR 置信度阈值，默认 `0.5` |
| `POLL_INTERVAL` | 轮询间隔，默认 `1.2` 秒 |
| `CLICK_COOLDOWN` | 点击后冷却时间，默认 `2.0` 秒 |
| `TARGET_ROI` | 每个目标允许点击的屏幕区域 |
| `CENTER_TARGETS` | 需要靠近屏幕中央排序的目标 |
| `ENABLE_RANDOM_SWIPE` | 未命中时是否随机上滑，默认关闭 |
| `SAVE_CLICK_DEBUG` | 是否保存点击调试截图，默认开启 |
| `ADB_PATH` | adb.exe 绝对路径，留空则自动查找 |

修改后保存，重新运行脚本即可生效。
